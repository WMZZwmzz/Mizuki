# 15 | SDXL 与 SD 3.5:画质它认输,人脉它说了算

> 文体:社区怀旧杂谈(老玩家口吻、有人情味、讲生态故事)
> 一句话:画质排行榜上它们早就不是第一名了,但社区里最热闹的,还是它们。

## 引子:为什么 2026 年还在聊 SDXL

我知道你在想什么:SDXL 都 2023 年的老古董了,有什么好聊的?

但你去 CivitAI 看一眼就懂了——**5000+ 个 LoRA** 摆在那儿,画风的、角色的、特定艺术家的,应有尽有。FLUX、Qwen 再强,新模型生态想追上这个存量,少说要一两年。这就是老家伙的江湖地位:论画质,它认输;论人脉,它说了算。

## 一、SDXL 1.0:生态之王的底气

**它凭什么还在打?**
- **5000+ LoRA**:从动漫到水墨,从赛博朋克到像素风,社区把能想到的风格全做了一遍。
- **5+ 类 ControlNet**:canny、depth、pose、scribble、union——姿势和构图控制,精度高到离谱。
- **最深的 inpainting 与工具链**:修图、局部重绘、高清修复,教程和插件管够。

**硬指标**
- 显存:6-8GB 就能跑,门槛低到离谱。
- 速度:配 Lightning LoRA 可 4 步出图,秒级响应。
- 许可:OpenRAIL++-M,可商用。

**它的软肋**:画质上限被新模型碾压;复杂提示词遵循一般;文字渲染基本等于没有——想要图里带字?另请高明。

## 二、SD 3.5 Large:被夹在中间的"过渡款"

SD 3.5 是 Stability AI 在 SD3 口碑翻车(SD3 Medium 的手和字都崩了)之后的修复之作,MMDiT 架构,8.1B 参数。

- 画质与提示词遵循:明显强于 SDXL。
- 显存:12-16GB(FP8 更省);LoRA 训练约 10GB。
- 许可:社区许可,可商用(月收入超百万美元需商业授权,以条款为准)。
- 尴尬之处:向上不如自家 SD4,向下不如 SDXL 生态——两头受气。

## 三、三代同堂怎么选

| 需求 | 选谁 |
|---|---|
| 风格 LoRA 广度、动漫/特定画风、低显存 | SDXL |
| 可商用的质量升级、12GB 显存 | SD 3.5 Large |
| 4K 原生 + 文字专项 + 私有化 | SD4(见 05 号文档) |

**过来人建议**:新项目先看 SD4;想要"一键找到想要画风"的省心体验,SDXL + CivitAI 仍然是答案。

## 四、ComfyUI 里的老伙计用法

1. SDXL:checkpoint 放 models/checkpoints/ 或 diffusion_models;配 VAE;教程最多,零基础友好。
2. SD 3.5:MMDiT 需对应节点;FP8 降显存;Large Turbo 适合快速迭代。
3. 通用:低显存 --lowvram / GGUF;LoRA 用 AI-Toolkit(Adafactor 适合 8.1B)。

## 五、FAQ(老玩家问答)

**Q1:2026 年还用 SDXL 丢人吗?** 不丢人。画质它认输,但你要找冷门画风,它是唯一解。
**Q2:SDXL 和 SD 3.5 哪个好?** 画质 3.5 好,生态 SDXL 好;按需求选。
**Q3:能商用吗?** 两者都可(读条款);SD4 以最新许可为准。
**Q4:SDXL 显存?** 6-8GB;Lightning LoRA 4 步。
**Q5:SD 3.5 显存?** 12-16GB(FP8);训练约 10GB。
**Q6:文字渲染?** 弱,基本不可用;要字用 Qwen-Image。
**Q7:ControlNet?** SDXL 5+ 类,姿势构图最强。
**Q8:怎么训 LoRA?** AI-Toolkit/kohya;CivitAI 现成资源一堆。

## 六、实战配方(社区沉淀的经典套路)

**A:动漫画风批量** — CivitAI 下 LoRA → 基础词 + LoRA(0.6-1.0)+ 负面词 → Lightning 提速批量。
**B:精确姿势** — pose/canny 骨架 → ControlNet 约束 → 角色设定/分镜/电商姿势。
**C:可商用升级** — 12GB 部署 SD 3.5 Large(FP8)→ 提示词遵循更好的商业素材。
**D:局部重绘** — Inpainting 工作流(生态最深),改脸/换背景/修瑕疵。

## 七、提示词技巧(老玩家的私货)

| 目标 | 技巧 |
|---|---|
| 风格一致 | 画风词 + LoRA(0.6-1.0) |
| 防畸形 | 负面提示词(手/手指/畸形) |
| 提速 | Lightning LoRA(4 步) |
| 构图 | ControlNet(canny/depth/pose) |
| 局部修 | Inpainting 工作流 |
| 高清 | 512-1024 生图 → 放大 |

## 八、风险与感慨

- 生态是护城河,也是包袱——新模型追上来后,存量优势会递减。
- 画质与文字短板,别拿它硬扛海报。
- 许可条款有附加限制,商用前读。
- SD3.5 位置尴尬,新项目建议评估 SD4。
- Stability 的江湖风波多,路线常变,多关注。
